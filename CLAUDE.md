# Worker Bee

## Dev Workflow
- Always git commit updates after changes unless instructed otherwise.
- Break large changes into multiple smaller commits grouped by related changes.
- After changes, make appropriate semantic version updates in the `apps/` directory.
- Always update documentation in @docs/ directory if relevant.
- Add documentation to @docs/ if relevant and link from the table below.
- When doing file explorations, use subagents that only retrun the results.
